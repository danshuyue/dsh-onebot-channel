## 二、主要修复

### 上游修复与 PR2 项

- 出站装饰段降级全部失败时抛错，避免 `message_id=0` 被当作成功。
- 修复出站失败后的队列双重 `shift`，避免错误移除下一条回复。
- `/save` 先完整校验 URL、端口和时间段，再写入配置，避免部分写入。
- `message_id` 锚点和 reply ID 按字符串整数处理，避免精度丢失。
- 群友身份识别改为包含「群友」标记，而不是只检查开头。
- 群上下文图片过滤无图消息，并限制数量、并发下载。
- 归档首选会话不再 fallback 到无关活动会话。
- 增加清凭据接口和设置页破坏性确认，密码输入使用 `autocomplete=new-password`。

### 0.16.1 新增修复

- 窗口 pending 消息和批次起始时间持久化；启动时恢复可恢复批次，无法恢复的活动窗口关闭。
- backfill 感知活动窗口资格，避免启动时在实时循环前越过触发者普通消息、再次 @ 或窗口引用消息。
- 活动窗口内再次 @ 会更新活动时间和窗口游标。
- 窗口批次图片设置总量上限，并按消息并发构建附件。
- 一次分条回复登记全部成功发送的 `message_id`，引用任意分段都能命中窗口资格。
- WS 入站、seenIds、窗口自发消息集合和出站回执保留无损字符串 ID。
- 批次处理失败增加指数退避，避免协议端故障时每秒重试。
- `windowEnabled=false` 时不传窗口专属 @ 限频标记，保持旧版行为。
- API 和设置页用有限数判断，保留配置值 `0` 的语义。
- `window-sim.mjs` 使用独立临时 HOME，测试不再写入真实 `~/.dsh`。

## 三、未采纳或按预期保留的项目

- **跨群“每人每日”额度：** 当前设置语义是每群内每人每日，跨群分别计数属于预期行为，未改动。
- **归档绑定 UI 标红：** 归档拦截和日志告警已实现；界面显式标红属于后续可选增强，不影响安全行为。
- **合法但不存在的 `reply_to`：** 当前校验整数形状，协议失败时会降级去引用重发正文；增加上下文 ID 白名单属于额外策略，不作为本次版本阻断项。
- **`atTargetsOf` / `qq_msg_history`：** 当前仍有有效测试和注册调用，不属于死代码或下线功能。
- **测试与对话说明中的身份信息：** 业务身份说明不等同于测试泄露；测试夹具中的真实样例编号已替换为占位值。
